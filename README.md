Personal Website – Fullstack Web Developer

🌐 [Live Demo](https://carabetcorneliu-next.netlify.app/)

This is my personal website built with Next.js, showcasing my work as a Fullstack Web Developer.
It highlights my skills, projects, and experience while serving as a central hub to connect with me.

## ✨ Features

- **Modern Stack**: Built with Next.js 14 App Router and TypeScript
- **Responsive Design**: Optimized for all devices and screen sizes
- **Performance Optimized**: Fast page loads and smooth animations
- **Dark Mode**: Built-in dark/light theme support

## 🚀 Sections

- **About Me** – A short introduction and my developer journey
- **Skills & Tech Stack** – Technologies I use, from frontend frameworks to backend tools
- **Projects** – A curated selection of web applications with live demos and source code
- **Contact** – Easy ways to get in touch for opportunities or collaborations

## 🛠️ Tech Stack

- **Frontend**: Next.js 14, TypeScript, Tailwind CSS
- **UI Components**: shadcn/ui
- **Icons**: Lucide Icons
- **Deployment**: Netlify
- **Form Handling**: React Hook Form
- **Animations**: Framer Motion

## 📦 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/carabetcorneliu/personalPageNextJS.git
   ```

2. Install dependencies:

   ```bash
   npm install
   # or
   yarn install
   ```

3. Run the development server:

   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser
